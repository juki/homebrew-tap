# Homebrew tap for FreeSWITCH Console

```sh
brew install juki/tap/fsconsole
```

Installs `fsconsole` and `fsconsole-agent` from the release archives of
[FreeSWITCH Console](https://github.com/juki/freeswitch-console), a web
console for operating FreeSWITCH over the Event Socket. macOS and Linux,
Intel and ARM.

```sh
fsconsole -demo      # simulated switches, nothing to set up
```
